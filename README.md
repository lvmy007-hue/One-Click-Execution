# 店表作业调度

每天把各店发到微信的地址表收齐，自动完成匹配和核验，再把结果私下发给对应的人。人不需要守在电脑前点按钮。

## 要解决什么

店里每天会发来一批「谁、住哪」的表。要做的事情固定且琐碎：

- 从微信里把表捞出来，按当天归档
- 补全详细地址、联系方式、邮箱
- 晚上再核验邮箱和通讯软件是否有效
- 把各店自己的结果发给店员，把总表发给指定的人
- 出错只通知负责人，不要发到群里刷屏

以前这些步骤要开匹配系统、核验系统、飞书，来回点。这个工具把当天这一整条作业串起来，按点执行。

## 它做什么

**收表**  
微信保持登录并打开「文件自动下载」后，表格会落到本机。工具按文件到达时间判断算哪一天：上午截止前算当天匹配，截止后算第二天。查出表（查地址/查邮箱）另外收进匹配目录。

**匹配**  
把当天店表交给本机的数据匹配系统：详细地址 → 联系方式 → 邮箱 → 补全剩余 → 三源合并。中途崩了会接着上次进度跑，不会把已经做完的再做一遍。

**核验**  
等到约定的晚上时间（中午前如果有当天新查出，可以提前）。把合并结果和查出表导入核验系统：邮箱预检、发信、iMessage / WhatsApp / Apple ID。做完导出精简包。

**送达**  
不进飞书群。按店把表打成压缩包私聊给店员（一店可以多人），总表发给指定的人，并抄送。报错走另一套告警机器人，只私聊负责人。

**监视**  
本机打开作业页可以看到今天收到哪些表、匹配/核验走到哪一步、飞书对照和截止时间也可以在页上改。

## 谁在用

本机操作人员。需要两台业务程序已经装好并能打开：

- 数据匹配系统
- 数据核验系统

以及企业飞书里的表格机器人和告警机器人（接收人要在应用可用范围内）。

## 一天大概怎样

上午：各店表陆续进来，过点进次日，不再加入当天匹配。  
白天：匹配在跑，详细地址包会先发给指定的人。  
傍晚：等到核验点（或中午前已有新查出则提前），跑核验。  
结束后：各店私聊收到自己的表，总表和抄送按设置发出。作业页显示当天完成。

收集进程全天挂着，只负责收文件，不等于当天匹配还在跑。

## 不做什么

- 不代替微信，也不从手机里抓聊天记录；只认已经下载到硬盘的表格
- 不在这个文件夹里改匹配/核验的算法，那是另外两套系统
- 不往群里发文件或提醒
- 不删除匹配数据目录里已生成的包
- 不是给店员用的网页，只在这台电脑本机打开
